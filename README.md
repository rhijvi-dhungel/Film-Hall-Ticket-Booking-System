🎬 Film Hall Ticket Booking System

A simple offline Film Hall Ticket Booking System developed as an academic project to simplify movie ticket reservations and demonstrate fundamental software development concepts.

📌 Project Overview

The Film Hall Ticket Booking System is designed to provide a straightforward movie ticket reservation experience. It allows users to select movies, choose available shows, reserve seats, and manage ticket bookings.

The application operates offline and focuses on implementing the basic workflow of a cinema ticket booking system.

✨ Key Features

Movie Selection: Select from available movies.

Show Selection: Choose a preferred movie show.

Seat Reservation: Select seats for the chosen show.

Ticket Booking: Complete ticket reservations.

Offline Operation: Use the application without an internet connection.
🛠️ Technologies Used

Programming Language: C++

Development Environment: Visual Studio Code (VS Code)

Database: Sqlite

🎯 Learning Objectives

Through this project, I explored:

Programming fundamentals and logical problem-solving.

Basic reservation and booking workflows.

User input handling and application logic.

Seat selection and ticket management concepts.

Development of an offline software application.
